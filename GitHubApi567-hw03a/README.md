# GitHub API - HW03a

[![Build Status](https://app.travis-ci.com/github-mahima/SSW-567-QA.svg?branch=main)](https://app.travis-ci.com/github-mahima/SSW-567-QA)

## Description

This project uses the GitHub API to retrieve repository names and the number of commits for each repository.

## Files

* `GitHubApi.py` - Contains the GitHub API functions.
* `test_GitHubApi.py` - Contains the unit tests.
* `requirements.txt` - Contains the Python dependency required by the application.
* `.travis.yml` - Configures Travis CI to run the tests.

## Running the Tests

From the `GitHubApi567-hw03a` folder, run:

```text id="q2z6bn"
python -m unittest test_GitHubApi.py
```

## Continuous Integration

The project is connected to Travis CI. Travis CI automatically runs the unit tests when changes are pushed to the `main` branch.
